[ 📖 SYSTEM GUIDE / 使い方 ]

■ BYAKUYA TOOLS 基本操作ガイド

  1. 1. APIステータス確認: 上部の「PORTAL API」がONLINEになっていることを確認します。
  2. 2. ツール検索: 検索バーにキーワード（例: `linejs`, `webhook`）を入力すると、対象ツールを即座に抽出できます。
  3. 3. セッション同期: Token Auto Sync機能により、認証トークンが自動的に保持・更新されます。
  4. 4. カラー変更: 右上のテーマスイッチャー（🌈 AUTO / 💚 / 💜 / 💙 / 💛）からネオンカラーを変更可能。

※Renderサーバーは一定時間アクセスがない場合サスペンドされるため、初回同期に数秒かかる場合があります。
